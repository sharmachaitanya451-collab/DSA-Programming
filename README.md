# DSA Programming Practice

This repository contains the Data Structures and Algorithms (DSA) problems I have been solving as part of my college learning and regular coding practice.

The main aim of keeping these solutions in one place is to track my progress, revise concepts, and get more comfortable with problem-solving using **Java**. The questions are taken from platforms like LeetCode, Codeforces, and GeeksforGeeks.

## What's inside?

The solutions are arranged into folders based on the topic, so they are easier to find and revise later.

| Folder | What it covers |
| --- | --- |
| `Array` | Array operations, searching, duplicates, and common array problems |
| `Basic Problem Solving` | Beginner-friendly logic, maths, and implementation problems |
| `Hashmap` | Frequency counting and finding distinct elements |
| `Stack` | Problems involving stack operations and string handling |
| `String` | String comparison, character manipulation, and related problems |

## Platforms

- [LeetCode](https://leetcode.com/)
- [Codeforces](https://codeforces.com/)
- [GeeksforGeeks](https://www.geeksforgeeks.org/)

Most solution files also include the problem name, platform, problem number, difficulty, and a link to the original question in the comments at the top.

## Language

All solutions in this folder are written in **Java**.

## How to use

1. Open the folder for the topic you want to practise.
2. Choose a `.java` file.
3. Read the problem details and try to understand the approach.
4. Run the code using a Java compiler or IDE.
5. If needed, visit the problem link in the comments and try solving it again on the original platform.

## A small note

This is an ongoing collection, not a collection of perfect or final solutions. I will keep adding problems as I learn new concepts and practise more. Some solutions may be simple approaches written while learning, and I may improve them later.

The goal is to stay consistent, understand the logic behind each problem, and gradually become better at DSA and coding.
